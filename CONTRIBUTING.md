# Contributing to CourseCraft

Thank you for contributing to CourseCraft! CourseCraft is an open-source, local-first browser extension designed to help students and self-learners streamline routine tasks on Coursera.

## Development Setup

1. Clone or copy the repository locally.
2. Open Chrome, Edge, or Brave and navigate to \`chrome://extensions/\`.
3. Toggle on **Developer mode**.
4. Click **Load unpacked** and select the repository root directory.
5. After making changes to any script in \`dist/\`, click the **Refresh** icon on the extension card in \`chrome://extensions/\`.

## Code Guidelines

- Keep code clean, modular, and un-obfuscated.
- Preserve local-first architecture and user privacy.
- Do not add remote telemetry, anti-debugging loops, or mandatory paid paywalls.
