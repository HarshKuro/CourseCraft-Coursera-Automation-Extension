# CourseCraft

> **Modern, Free & Local Coursera Study & Automation Assistant**

CourseCraft is a privacy-first browser extension designed to streamline routine learning tasks, backup course materials for offline study, bulk-complete lectures, and assist with quiz practice on Coursera.

![Version](https://img.shields.io/badge/version-4.0.0-indigo)
![License](https://img.shields.io/badge/license-MIT-emerald)
![Platform](https://img.shields.io/badge/platform-Chrome%20%7C%20Edge%20%7C%20Brave-blue)

---

## ✨ Features

- **⚡ Skip Video+**: Complete all course video lectures in bulk directly through official client events.
- **📹 Watch Lecture**: Auto-complete and advance the currently active video lecture.
- **📖 Reading Material**: Instantly mark reading articles as completed.
- **💬 Discussion Prompts**: Submit discussion participation entries.
- **🤖 AI Coach Dialogue**: Complete interactive coach and dialogue items.
- **🧩 Practice Widgets**: Submit ungraded plugin exercises.
- **📦 Course Backup**: Export course outline, videos, and materials into an organized ZIP archive.
- **🔗 Shareable Link**: Instantly copy peer-review assignment URLs to your clipboard.
- **🧠 Quiz Assistant**: Smart question helper with attempt history and **free Google Gemini AI** integration (bring your own free API key).

## 🚀 Installation

1. Open your browser and navigate to `chrome://extensions/` (or `edge://extensions/`).
2. Enable **Developer mode** using the toggle switch in the top-right corner.
3. Click the **Load unpacked** button.
4. Select this directory:
   ```
   C:\Users\harsh\Music\coursera-automation-extension-master
   ```
5. CourseCraft will appear in your extension toolbar. Pin it for quick access!

---

## 🎮 How to Use

1. Open any course on **[Coursera](https://www.coursera.org/)**.
2. Click the **CourseCraft** extension icon (or press `Alt + W` / `Alt + B`).
3. Click the task you want to run.
4. Check real-time progress via floating notifications.

---

## 🔑 AI Quiz Assistant Setup (100% Free)

CourseCraft supports free AI-assisted quiz solving using Google's generous free Gemini Flash API:
1. Open Google AI Studio at **[aistudio.google.com](https://aistudio.google.com/app/apikey)**.
2. Sign in with your Google account and click **Create API Key**.
3. Open CourseCraft **Settings** (gear icon in the popup).
4. Navigate to the **AI Quiz Assistant** tab and paste your API key.
5. Click **Test Connection** and **Save AI Settings**.

*(All other features—Videos, Readings, Discussions, Backups, Shareable Links—operate 100% locally and do not require any API key).*
