Frequently Asked Questions

Everything you need to know about CourseCraft.

Is CourseCraft completely free and open-source? ▼
Yes! CourseCraft is 100% free under the MIT License. There are no paid tiers, no subscriptions, no tracking pixels, and no data telemetry. The complete source code is publicly available on GitHub.
How does CourseCraft bypass Coursera's video validation? ▼
Instead of sending fake API calls that Coursera's server rejects with "Video completion validation failed", CourseCraft hooks the actual HTML5 video element on the lecture page. It plays the final seconds at 16x speed, allowing Coursera's native Video.js player to dispatch genuine authenticated stream heartbeats before auto-clicking next.
Which browsers are supported? ▼
CourseCraft is built on the modern Manifest V3 extension standard and runs on Google Chrome, Microsoft Edge, Brave, Opera, Arc, and any Chromium-based desktop browser.
How do I install the extension from the ZIP file? ▼
1. Download and extract the latest CourseCraft ZIP file.
2. Open chrome://extensions/ in your browser and enable "Developer mode" (top right).
3. Click "Load unpacked" and select the extracted folder.
